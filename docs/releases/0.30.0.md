# ManiOS 0.30.0 — an installer with profiles

0.30.0 installs ManiOS the way Debian does: one CD, a few questions, and a
system made for its job — a desktop, a server, or a server that also runs
DOS programs. ManiDE and ManiDOS become packages, `pkg` learns
dependencies and groups, and an installed disk gets a data partition for
packages and files. The plan: [ADR-0011](../adr/0011-debian-style-installer.md);
the guide: [docs/install.md](../install.md).

## Two ISOs

- **`manios-0.30.0-offline.iso`** (9.8 MB): the live system, the installer
  and the whole signed package repository (`REPO`). Installs without a
  network.
- **`manios-0.30.0.iso`** (3.4 MB, built by CI): the same without `REPO`.
  An installed system fetches its packages from manios.nl at its first
  start.

Both boot the full live system (ManiDE, ManiDOS) as before.

## The installer

- `install` with no arguments asks step by step, each step with a default
  that Enter takes: keyboard, network (DHCP or a static address, gateway,
  DNS), host name, disk, profile (plus more packages), where packages come
  from, then a summary to confirm.
- Profiles: **desktop** (ManiDE and ManiDOS; starts into ManiDE),
  **server** (the shell, the network and `pkg`), **server-dos** (ManiDOS
  and the DOS tools), **custom** (the packages you name).
- For scripts: `install -y --profile server-dos --pkg unzip --hostname srv
  --net 10.0.0.5/24,10.0.0.1 --dns 10.0.0.1 ata0`. `install DISK
  KEY=VALUE` still works as before (the boot partition only).
- The disk gets the **base system** (`BASE.BIN`: ManiOS without ManiDE and
  ManiDOS, 1.42 MB instead of 1.87 MB) and a **FAT16 data partition** up
  to 2 GiB (`/n/ata0p2`): packages, `home/`, `manios/etc/rc`.
- From the offline ISO, the signed index and the packages are copied onto
  the data partition, so the CD can come out at once.
- At its first start the installed system runs **`setup`**: it installs
  the profile's packages (from that copy, or over HTTP), deletes the
  copies and restarts once. The kernel finds partitions only when it
  starts, so this is done at the first start rather than by `install`,
  as Debian's base-config once did. Later starts run `manios/etc/rc`.
- **`mkfat`**: FAT16 file systems (2 MiB to 2 GiB) on a partition or a
  range of a disk (in the base system).

## Packages

- **`manidos`** (`dos`, `dosrun`) and **`manide`** (ManiDE and its
  programs) are packages. On the full system they are built in, and `pkg`
  never downloads them (`pkg info manidos`: *Part of this system*).
- **Dependencies:** `requires` in the index. `pkg install` installs what
  a package needs first (`arj needs manidos`), and `pkg remove` refuses
  to take away what an installed package needs (`-f` to force). Every DOS
  package needs `manidos`.
- **Groups:** `pkg install @dos-tools` (15 DOS tools); `pkg list` shows them.
- **A directory as the repository:** `pkg -u /n/cd0/REPO update`, checked
  exactly like the network (signature, SHA-256).
- The repository has 29 packages. `pkg` from 0.29 reads the new index
  and ignores what it does not know.

## Other changes

- `tools/mkiso.py`: subdirectories, large directories, full path tables;
  entries sorted by name. `make iso CD_REPO=DIR` adds the repository.
- `tools/mkrepo.py`: native packages built from the tree, `requires`,
  groups, `--cd` (the CD's copy with 8.3 names, sources in `SRC/`).
- ManiDE reads its session from its package when there is no
  `/boot/etc/manide`. The boot message suggests only programs that are
  there. `pkg` handles up to 16 commands per package.

## Tests

- `make test` passes, with two new tests. `base_system_test.py`: the base
  system has no ManiDE or ManiDOS but has `pkg`, and `BASE.BIN` is on the
  ISO. `installer_test.py`: a server install from the ISO, a data
  partition the host's mtools and fsck.fat accept, `setup` once and not
  again, `mkfat`, refusals.
- With the signed repository (outside the tree; it needs the key), on
  QEMU's BIOS, each onto a blank disk then booted from the disk alone:
  - desktop from the offline ISO, no network: ManiDE starts with its session;
  - server: no packages, no DOS, no desktop;
  - server-dos with unzip: ManiDOS, the DOS tools, and FIND finds a line;
  - the interactive installer answered step by step;
  - desktop from the ISO without `REPO`, packages over HTTP at the first start.
- `pkg`: dependencies first, removal refused and joint removal, groups,
  built-in packages (43 checks); the base system installing `manidos`
  with `arj` and keeping it across a reboot (5); offline from the CD (6).

## Known limits

- The full system needs 7026 KiB of the 7040 KiB a 7 MiB QEMU machine
  offers. `setup` and `mkfat` are in the base system only to keep it so;
  the next growth of the live system makes 8 MiB its minimum.
- The data partition is FAT16: at most 2 GiB, 8.3 names.
- The offline ISO is built locally: the repository is signed with a key
  CI does not have.
- One keyboard layout (US); no user accounts.
