# ManiOS 0.30.0 — installer, profiles and dependencies (in progress)

0.30.0 brings a Debian-style installer with profiles (desktop, server,
server with DOS, custom), a data partition and offline packages from the
CD: [ADR-0011](../adr/0011-debian-style-installer.md). This page grows as
the parts land.

## Done so far

- **`pkg` dependencies:** `requires` lines in the index; `pkg install`
  installs what a package needs first, `pkg remove` refuses to remove
  what an installed package needs (`-f` to force).
- **ManiDOS as a package:** `manidos` (`dos`, `dosrun`), a native package
  built from this tree. Every DOS package requires it. Where ManiDOS is
  built into the system (`/boot/bin`), `pkg` counts it as installed and
  never downloads it.
- **Groups:** `group` lines in the index; `pkg install @dos-tools`.
- `tools/mkrepo.py`: native packages from the build, `requires`, groups.
- Older `pkg` (0.29) reads the new index and ignores what it does not know.
- **The base system:** `build/base/manios-base.bin`, the same kernel and
  programs without ManiDE (`manide`, `desktop`, the desktop apps) and
  ManiDOS (`dos`, `dosrun`, `AUTOEXEC.BAT`): 1.42 MB instead of 1.87 MB.
  The ISO carries it as `BASE.BIN` for the installer; the live CD still
  boots the full system. The boot message suggests only what is there
  (`pkg` instead of `manide` and `dos`).

## Tests

- `tests/base_system_test.py` (in `make test`): the base archive is the
  full one minus ManiDE and ManiDOS, the ISO carries `BASE.BIN`, and the
  base kernel boots without `dosrun` and `manide` but with `pkg`.
- With the signed repository (outside the tree, it needs the key): on the
  base system `pkg install arj` installed `manidos` first, arj made and
  listed an archive through the installed `dosrun`, `pkg remove manidos`
  was refused while arj was installed, and after a reboot arj still ran
  and both packages were removed. On the full system `manidos` counts as
  built in, `@dos-tools` installs the group, and `requires` puts
  dependencies first (43 checks).
