# ManiOS 0.31.0 — servers

ManiOS can now be a server. Programs listen for TCP connections, there is
a random number source for keys, and the shell runs commands in the
background and stops them again. On top of that, five servers came to
the package repository from manios-apps: **sshd**, **httpd**,
**telnetd**, **ircd** and **ftpd** (`pkg install @servers`).

## Listening for connections

- **`announce("tcp!*!PORT")`** returns a descriptor that listens on PORT
  (every address); **`accept_conn(fd, remote, len)`** waits for a
  connection, returns its descriptor (a byte stream, as `dial()` gives)
  and says who is at the other end (`A.B.C.D!PORT`). The listening
  descriptor polls readable while connections wait; closing it stops
  listening. A port that is listened on already gives `EADDRINUSE`.
- The kernel answers a SYN on a listened port from SYN_RCVD, retransmits
  its SYN-ACK, and queues the connections whose handshake is done (up to
  16 per port, half-open ones included) until they are accepted. A SYN to
  a port nothing listens on is still not answered.
- System calls `SYS_ANNOUNCE` (33) and `SYS_ACCEPT` (34), under ABI
  version 2.

## /dev/random

Every interrupt stirs a pool with when it came (the PIT's count, and the
TSC on CPUs that have one); a read hashes it with SHA-256 into the bytes
it gives, and the pool moves on by a path no output takes. Reads never
block. Writing to it mixes in what is written. sshd's keys, its key
exchange and the servers' password salts come from it.

## Jobs, kill and ^C

- **`COMMAND &`** runs a command in the background: the shell says its
  pid and goes on, and before a later prompt says when it is done (or
  killed). **`jobs`** lists the running ones.
- **`kill PID`** (a shell builtin; `SYS_KILL`, 35; `kill(pid, sig)` and
  `proc_kill()` in libc) stops a process: it exits (status `ZKT_WAIT_KILLED |
  ZKT_KILL_VECTOR`, shown as killed), and whatever it is waiting on — a
  read from the console, a pipe or a connection, `accept`, `wait`,
  `poll`, `sleep` — gives up with `EINTR` first.
- **^C** on the console stops the command the shell waits for (the shell
  tells the console which processes those are: `fg PID...` to
  `/dev/consctl`); at a prompt it drops the line typed so far.
- **`> FILE`** now makes the file (or empties it), and **`>> FILE`** adds
  to its end. Devices are written as before.
- Raw mode ends when the process that turned it on closes `/dev/consctl`
  (before, any close ended it).

## Size

The full system still boots on a 7 MiB machine (it needs 6010 of the
6016 KiB such a machine has above 1 MiB). To keep it so, `kill` is a
builtin rather than a program, and the new test program `ltest` is put
on the tests' disks instead of into the boot archive.

## libc

- `x25519()`, `x25519_base()`, `ed25519_public_key()` and
  `ed25519_sign()` beside `ed25519_verify()` (`<ed25519.h>`), checked
  against the RFC 7748 and RFC 8032 test vectors.
- `kill()`, `announce()`, `accept_conn()`, `proc_kill()`; `strerror()`
  knows `ESRCH` and `EINTR`.

## Servers (manios-apps 1.3.0, `pkg install @servers`)

All need ManiOS 0.31.0. Each logs to standard output; start them with
`&`, or at every boot from the disk's `manios/etc/rc` (see
[servers](../servers.md)).

- **sshd** — `sshd -g KEYFILE` makes an Ed25519 host key;
  `sshd -k KEYFILE -A AUTHKEYS -P PASSFILE &` serves logins with an
  Ed25519 key (lines as in `authorized_keys`) or a password (lines made
  with `sshd -H`). curve25519-sha256 key exchange (strict, against the
  Terrapin attack), ssh-ed25519 host key, chacha20-poly1305@openssh.com:
  nothing older is offered. `ssh HOST` gives a shell (sshd edits the
  line: Backspace, ^U, ^C), `ssh HOST COMMAND` runs one and returns its
  exit status. Three connections at once; no forwarding, scp or sftp.
  Works with OpenSSH 10.
- **httpd** — `httpd [-p PORT] [DIR] &`: files over HTTP (GET, HEAD),
  `index.html` or a directory listing, MIME types, `..` refused, one log
  line per request.
- **telnetd** — `telnetd -P PASSFILE &`: a shell for telnet clients, the
  password asked with echo off. Telnet is unencrypted: use sshd beyond
  your own network.
- **ircd** — `ircd [-n NAME] &`: an IRC server for up to 12 people
  (channels, private messages, topics, NAMES, WHO, WHOIS, AWAY, PING).
  The `irc` client from `@net` talks to it.
- **ftpd** — `ftpd -P PASSFILE [-w] DIR &` (or `-a` for anonymous):
  passive-mode FTP; LIST, RETR, and with `-w` STOR, MKD, RMD, DELE,
  renames. Users can't leave DIR.

The source is published beside the packages, at
<http://manios.nl/repo/src/manios-apps-1.3.0.tar.gz>.

## Tests

- `make test` passes, with two new tests:
  - `tests/net_listen_test.py`: `/dev/random`; a second listener on a
    port refused; 256 KiB echoed both ways through an accepted
    connection; a second client waiting in the backlog; nothing answers
    once the listener is closed.
  - `tests/jobs_test.py`: `&`, `jobs` and the done message; `kill` of a
    sleeping job and of a pid that isn't there; ^C on a program blocked
    in `accept`, on a pipeline and on a half-typed line, and the port
    free again afterwards; `>` and `>>`.
- manios-apps `tests/servers_test.py` runs all five servers in the
  background on ManiOS in QEMU and talks to them from the host: OpenSSH
  logs in with a key (a command's output and exit status, 300 KiB of
  output, standard input to its end) and with a password to an
  interactive shell; urllib fetches a 150 KiB file six times at once;
  telnet, IRC and FTP sessions; `kill` stops all five.
