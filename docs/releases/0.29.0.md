# ManiOS 0.29.0 — packages and TCP/IP

0.29.0 lets ManiOS install software from the internet: a package manager,
`pkg`, and the ManiOS package repository at <http://manios.nl/repo/>. To
get there ZKT gained TCP, DNS and an HTTP client. Full guide:
[docs/pkg.md](../pkg.md).

## Networking

- **TCP** (`zkt/net/tcp.c`): connections as stream files. Active open,
  in-order delivery, retransmission with back-off, flow control both ways,
  orderly close. A new system call, `SYS_DIAL("tcp!HOST!PORT")` (libc
  `dial()`), returns an ordinary descriptor.
- **DNS** (`zkt/net/dns.c`): A records from the server DHCP offers (now
  requested, option 6), or `dns=A.B.C.D` on the kernel command line; a
  small cache honours TTLs.
- **HTTP/1.1 client** in libc (`<http.h>`): GET with Content-Length or
  chunked bodies and redirects to other `http://` URLs. `hget URL [FILE]`
  fetches a URL from the shell. There is no TLS: plain HTTP only.
- New error numbers: `ECONNREFUSED`, `ECONNRESET`.

## Packages

- `pkg update | list [-i] | search | info | install | remove | upgrade`.
  Packages go to the first writable FAT disk (`/n/DISK/manios/pkg`);
  their commands work at once and, after a reboot, the kernel adds them
  to `/bin` again.
- **Trust without TLS:** the package list must carry a valid Ed25519
  signature by the repository key built into `pkg`, and every package must
  match the size and SHA-256 that list gives. libc gains SHA-256, SHA-512
  and Ed25519 verification (`<sha256.h>`, `<ed25519.h>`; the Ed25519
  arithmetic follows the public-domain TweetNaCl).
- **The repository starts with 25 DOS programs**, each one Working in the
  [compatibility list](../dos-compatibility.md) and freely licensed (GPL,
  MIT, BSD, EUPL, public domain): arj, attrib, b64, bc, bsum, cal,
  deltree, du, fc, fdbanner, grep (`dgrep`), gzip, head (`dhead`), mem,
  more, printf, rcal, search, sleep (`dsleep`), tee (`dtee`), touch,
  utf8tocp, xdel, xgrep and zoo. Each is published with its unmodified
  FreeDOS source package. Native ManiOS packages use the same format and
  can be added alongside.
- `tools/mkrepo.py` builds and signs the repository from
  `repo/packages.json`; it refuses programs that are not Working, names
  that are not 8.3, and missing files.

## Kernel and dosrun

- **`#!` scripts:** a file starting `#!INTERPRETER [ARG]` runs through its
  interpreter, as on Unix.
- **dosrun launchers:** `#!/bin/dosrun --launcher` scripts name the DOS
  program to run (`program`, `env`, `envpath`, `mount` lines). A launched
  program starts in the shell's current directory.

## Fixed

- **FAT12 writes:** setting a FAT12 entry for an even-numbered cluster kept
  the old bits of its first byte, so linking a file's second cluster onto
  an end-of-chain marker left the marker in place: files on FAT12 volumes
  broke after two clusters (input/output error). Found by the Android data
  disk; `tests/net_tcp_test.py` now writes 256 KiB onto a FAT12 volume.

## Android

The 0.29.0 app (`com.manios.emulator`, versionCode 29000) turns on the
virtual network (QEMU user networking, an e1000 card) and adds a 16 MiB
FAT data disk, created on the first launch and kept afterwards, so `pkg`
works on Android. Installed on an Android 10 emulator: it booted into
ManiDE with the network up, `pkg update` read the 25 packages from
manios.nl, `pkg install cal` installed, and the package was still
installed after the app was restarted. Signed with the same certificate
as earlier versions, so it upgrades them.

## Tests

- New `tests/net_tcp_test.py`: TCP downloads from the host byte for byte,
  HTTP 404, a refused connection, `#!` scripts and a launcher.
- On the live site: a ManiOS VM ran plain `pkg update` against
  http://manios.nl/repo, installed arj, zoo and bc, and arj created and
  listed an archive.
- End-to-end in QEMU: `pkg` fetched the signed list from a local copy of
  the repository, installed all 25 packages, each command did its
  recorded task, removal worked, the commands came back after a reboot,
  and a tampered package and a tampered list were both refused.

## Known limits

- Plain HTTP only: the website must serve `/repo/` over HTTP as well as
  HTTPS (see the Nginx note in docs/pkg.md).
- Packages need a writable FAT disk. A disk prepared by `install` holds
  only the boot partition, so such systems need a second FAT disk for now.
- FreeDOS FIND and Info-ZIP UnZip are not packaged yet: this FIND looks
  for relative names on A:, and FreeDOS 1.4's UnZip is a 32-bit DJGPP build
  that needs DPMI. (Both added in [0.29.1](0.29.1.md).)
- DOS programs draw an 80x25 screen: in a small ManiDE terminal tile
  their output is lost; use Alt+Space for the full-screen layout.
- TCP is client-only (no listening sockets) and drops out-of-order
  segments rather than queueing them.
