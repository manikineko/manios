# ManiOS 0.30.1 — keys one at a time, and the first apps

The console and ManiDE's terminal learned to hand programs their keys one
at a time. The first programs written for the package repository use it:
**edit**, a text editor, and the games **snake** and **mines**. They live
in their own repository, **manios-apps**, not in the system's source.

## manios-apps (`pkg install edit`, `pkg install @games`)

Programs of their own are kept apart from ManiOS: the `manios-apps`
repository has one directory per program, a Makefile that builds them
against a ManiOS source tree (`make MANIOS=../manios-git`), their tests
(`make test`, in QEMU on that tree's kernel) and `packages.json`, which
`tools/mkrepo.py` reads beside this tree's recipes (`--recipes` twice).
Its packages have their own versions (1.0.1), and its source is published
beside them: <http://manios.nl/repo/src/manios-apps-1.0.1.tar.gz>.

### edit

A full-screen editor for the console and ManiDE's terminal:

```
edit [FILE]
```

- Arrows, Home/End, PgUp/PgDn, Backspace and Delete edit as you would
  expect; Enter splits a line, Backspace at the start joins it to the one
  before, Delete at the end joins the next.
- `^O` save, `^X` exit (it asks when there are unsaved changes), `^W`
  find (again: the last word is offered), `^L` go to a line, `^K` cut the
  line (several in a row go together), `^U` paste them, `^R` redraw.
- A file whose lines end in CR LF (DOS) is saved the same way.
- Tabs show as spaces to the next multiple of 8. The screen size comes
  from the terminal (`ESC [ 18 t`), 80x24 otherwise; only changed rows are
  redrawn, so it stays quick over a serial line.

### snake and mines

- **snake:** steer a growing snake to its food with the arrows (or
  w a s d); it speeds up as it grows; p pauses, q quits.
- **mines:** open every cell without a mine; numbers count the mines
  around; f flags; Space on a number whose mines are flagged opens the
  rest around it. `-e` 9x9, `-m` 16x16 (default), `-x` 30x16, `-c WxH:N`.
  The first cell is never a mine.

## Raw keys

- **The console:** `/dev/consctl` takes `rawon` and `rawoff`, as in Plan 9.
  In raw mode a read returns the keys as they come, unechoed; the PS/2
  keyboard's arrows and editing keys arrive as the ANSI sequences a
  terminal sends (`ESC [ A`, `ESC [ 3 ~`, ...). Closing it ends raw mode;
  reading it says which mode the console is in.
- **ManiDE's terminal:** a program that prints `ESC [ ? 7727 h` gets each
  key as it is pressed, until `ESC [ ? 7727 l`.
- **libc:** `con_raw(1)` / `con_raw(0)` does both (`<manios.h>`).

## pkg

- `minos` in the index: the oldest ManiOS a package runs on. `pkg`
  refuses to install a package that needs a newer system and says so;
  `pkg info` shows it. `edit` needs 0.30.1, `find` 0.29.1. (Older `pkg`
  ignores the line.)
- `tools/mkrepo.py` builds one repository from several recipe files
  (`--recipes`), each with its own root for native files, source URL
  and versions.
- The repository has 32 packages; group `@games`.

## Android

The 0.30.1 app (`com.manios.emulator`, versionCode 30100) carries the
0.30.1 system, so edit and the games work in its ManiDE terminal; same
certificate, so it upgrades earlier versions.

## Tests

- `make test` passes (the device list now includes `consctl`).
- manios-apps `tests/edit_test.py`: a new file typed over the serial
  line (Enter, Up, Home, `^O`, `^X`); a DOS file keeps CR LF, End and
  Delete join lines; `^K`/`^U`; `^W` and `^L`; `^X` with changes asks
  and `n` leaves the file; the PS/2 keyboard's End, Left, Ctrl+O, Ctrl+X;
  the console cooked again afterwards; `edit` inside ManiDE's terminal
  with keyboard keys, then the shell in that pane reading lines again.
  Each file is read back on the host.
- manios-apps `tests/games_test.py`: snake steered to its food by
  following its head on screen (fixed seed), paused, crashed, restarted;
  mines won on a one-mine field, lost on a crowded one, a flag, a new game.
- Package E2E: `pkg install edit`, then editing a file with it; a package
  with `minos 9.0` is refused.
